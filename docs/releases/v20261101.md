# kcptun v20261101

Based on master commit ecc88d14c172a31205f65b613f9578878540fd77 (PR #28).

## Fixes

- Prevent slow or failed tunnel setup from blocking the client accept loop. Setup is bounded to one pending request per tunnel slot; requests assigned to a busy slot close immediately and applications should retry. Failed setup is retried by later connections.
- Reject overflowing SNMP logging intervals at startup instead of panicking.
- Support the full documented rate-limit range (0–4294967295 bytes/second) on both 32-bit and 64-bit builds.

## Downloads

Each platform archive contains the client and server binaries. Linux ARM5/6/7, ARM64, amd64, 386, MIPS/MIPSLE softfloat and Loong64; Windows amd64, 386 and ARM64; macOS amd64 and ARM64; FreeBSD amd64.

Verify downloads using SHA256SUMS. Configuration and protocol defaults are unchanged.

## Validation

PR CI passed race-enabled unit tests, static analysis, invalid-configuration tests and TCP EOF/QPP integration tests. Release CI builds all target archives and runs additional verification on Linux amd64. Cross-compilation does not substitute for runtime testing on every target device.
