# KCPTUN v20261029 — runtime safety and configuration fixes

This release packages the audited `master` changes merged in PR #26. Both the client and server are included in every platform archive.

## Fixes

- Client remote address parsing is performed for each dial configuration instead of reusing a process-global cached destination; this prevents a later configuration from using the wrong remote endpoint.
- Validate outbound KCP pacing rate before conversion to `uint32`. Values above `4294967295` bytes/second are rejected instead of silently wrapping. A negative rate remains normalized to zero for backward compatibility.
- Restrict opt-in Go profiling (`--pprof`) to `127.0.0.1:6060` rather than all network interfaces to avoid accidental exposure.
- Reject multiple JSON values and trailing invalid content in configuration files instead of silently accepting only the first value.
- Close underlying KCP transports if SMUX session creation fails to avoid leaking network resources.
- Add unit and integration regressions plus a continuous pull-request and master CI workflow (race detector, `go vet`, invalid configuration tests, TCP half-close and QPP).

## Compatibility

The transport protocols, on-wire framing, and vendored dependencies are unchanged. Remote access to profiling now requires an explicitly configured secure tunnel. Positive rate limits larger than `4294967295` are invalid instead of silently wrapping.

## Downloads and verification

Release archives `kcptun-<os>-<arch>-20261029.tar.gz` contain both `client_*` and `server_*` executables; Windows binaries have `.exe` extensions. The build covers 15 targets across Linux, macOS, Windows, and FreeBSD. `SHA256SUMS` lists the archive checksums.

The Linux/amd64 client and server are executed against integration tests in GitHub Actions. Other targets are cross-compiled and package-verified but not executed on their target operating systems. All release assets are published only after the release build matrix succeeds.
