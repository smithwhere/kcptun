## 主要更新

- 客户端启动时预建会话，并改进连接重试、超时和资源管理。
- 修复 smux 建流时过早响应丢失、写入超时后的排队数据以及连接关闭与半关闭问题。
- 改进压缩与 QPP 并发处理、tcpraw 报文和防火墙错误处理，并补充回归测试。

## 验证

- Windows 和 Linux 竞态检测、静态检查，以及 TCP/QPP 集成测试通过。
- 该版本由 GitHub Actions 从本发布提交重新构建，包含 15 个平台的客户端和服务端。每个归档的 SHA-256 见 `SHA256SUMS`。

## 已知限制

- 实验性的独立进程监管尚未接入客户端实际会话。如果底层调用永久阻塞，拨号额度仍可能耗尽。
- Linux 原始套接字和防火墙路径尚未完成真实权限环境下的端到端验证。
