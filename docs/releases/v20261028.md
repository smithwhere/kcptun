# KcpTun v20261028 — configuration and Docker fixes

## Fixes

- Docker builds now use vendored dependencies, preserving the smux half-close fix that prevents buffered data loss.
- Reject client connection counts outside 1–65535 and QPP counts outside 1–65535 before they can be truncated.
- Validate smux settings at startup, including a positive keepalive interval, instead of allowing invalid settings to crash a running process.

## Downloads and verification

Each archive contains client and server binaries for the named platform. Use SHA256SUMS to verify downloads. The release workflow runs race and loopback regression tests on Linux amd64; other targets are cross-compiled and packaged.
